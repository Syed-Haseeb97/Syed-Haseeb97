## 🤖 Current Main Focus

### **[Ruby — AI Screen Assistant](https://github.com/Syed-Haseeb97/ai_agent)**

A personal Windows AI agent designed to operate as a real desktop assistant rather than just a chatbot.

Ruby combines **Gemini-powered reasoning, voice interaction, screen awareness, browser automation, computer control, memory, and multi-step task execution** into one local assistant.

**What I'm exploring:**

- 🧠 LLM-powered reasoning and agent workflows
- 🎙️ Voice input, TTS, and wake-word interaction
- 🖥️ Screen awareness and computer-use actions
- 🌐 Browser automation with Playwright/Chromium
- 🖱️ Mouse and keyboard automation
- 🧩 Tool/action execution for real-world tasks
- 🧠 Persistent memory and contextual preferences
- ⚙️ Multi-step commands and task orchestration
- 🔐 Local-first control with explicit configuration

> **Goal:** build AI systems that don't just answer questions — they can **understand, decide, use tools, and execute**.
